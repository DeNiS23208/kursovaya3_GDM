## 📌 Описание проекта

Приложение для анализа вакансий и компаний с сайта hh.ru.  
Собирает данные через API hh.ru, сохраняет их в PostgreSQL, а затем позволяет взаимодействовать с базой данных через интерфейс.

Цель проекта — продемонстрировать навыки работы с базами данных, API, обработкой данных и проектированием архитектуры по SOLID-принципам.

---

## 💡 Что умеет проект

- Получать данные о 10 компаниях и их вакансиях с hh.ru
- Хранить данные в PostgreSQL с правильными связями (FK)
- Позволять пользователю:
  - Посмотреть компании и количество вакансий
  - Посмотреть все вакансии
  - Узнать среднюю зарплату
  - Найти вакансии с зарплатой выше средней
  - Искать вакансии по ключевому слову
